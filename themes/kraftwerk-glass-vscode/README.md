# Kraftwerk Glass VS Code Themes

Three dark glass-style themes:

- Kraftwerk Glass Emerald
- Kraftwerk Glass Sapphire
- Kraftwerk Glass Ruby

Install locally by copying this folder to your VS Code extensions directory, then reload VS Code.

Windows:
%USERPROFILE%\.vscode\extensions\kraftwerk-glass-themes

Linux/macOS:
~/.vscode/extensions/kraftwerk-glass-themes
