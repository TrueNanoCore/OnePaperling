# MERMAID QUALITY RULES

1. Clarity over compactness.
2. Prefer multiple diagrams over a large unreadable diagram.
3. Group related concepts.
4. Use clear labels.
5. Show directions explicitly.
6. Minimize line crossings.
7. Use meaningful node names.
8. Ensure Obsidian compatibility.
9. Use pure Mermaid code blocks.
10. Split large systems into sub-diagrams.

- Use colors sparingly.

- Agent types

- Domains

- Responsibilities

Never sacrifice readability for aesthetics.
